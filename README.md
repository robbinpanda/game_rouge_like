# 畸变前线 · 回响远征 (Aberrant Frontier: Echo Expedition) `v0.4`

一款基于 **Three.js + Blender 5.3** 打造的 3D 赛璐璐风格动作 Roguelite（肉鸽）游戏，支持单文件离线即开即玩。

## 快速开始

- **直接游玩**：双击根目录的 [`畸变前线-回响远征.html`](./畸变前线-回响远征.html)（无需联网或安装依赖，推荐 Chrome / Edge 并开启硬件加速）。
- **开发构建与测试**：
  ```bash
  cd aberrant-frontier-v4
  npm run build:rogue   # 重新构建 dist/rogue-game.js 与单文件离线版
  npm test              # 运行 77 项自动化测试
  ```
- **Blender 模型重建**：
  ```bash
  blender -b -P game-workbench/tools/build-echo-creatures.py       # 怪物与首领模型
  blender -b -P game-workbench/tools/build-sanctuary-panorama.py   # 3D 圣所与三域全景
  ```

## 核心特色

- **塞尔达式宏大世界俯瞰开场动画 + 哈迪斯式「远征圣所」大厅**：实时 3D 渲染圣所高台与三幕地貌全景（晴湾断轨、鸣潮船坞、紫晶温室与通天光柱），支持大厅自由切换俯瞰与重播开场。
- **局外长线成长系统**：
  - **回响之镜**：使用局内外均可带回的「回响残片」解锁 7 项永久强化（残火续命、流影步二段闪避、厚甲体魄、余温汲取、回响亲和、命运重骰、商队信物）。
  - **共鸣预言碑**：10 项命运预言里程碑，局内达成即享丰厚残片奖励。
- **三门分支选择 + 武器质变锻炉**：清场开启 2~3 扇带 3D 发光标识的奖励门（四系回响、武器质变锻炉、生命圣泉、晶片宝库、精英双赏、双系试炼、回响祭坛等），全部 6 把武器各含 2 项改变招式形态的质变改造。
- **5 位可玩异变者（含「岚影」）**：烬刃（刃温）、霜序（霜压）、岚影（影印）、裂爪（裂伤）、玄岩（岩势），各自拥有独立资源循环与专属回响。
- **高速丝滑动作手感**：独立多段闪避、**冲刺斩（Dash-Strike）**、输入缓冲、目标软锁定（`V` / 鼠标中键）、360° 脚底威胁方向弧光、怪物独立受击闪白与挤压拉伸、晶化爆裂 + 磁吸晶片、清场史诗慢镜头。
- **赛璐璐漫画视觉升级**：Blender 5.3 重制 7 种怪物与 3 位体量强化首领、统一 4 阶 Toon 着色与反转法线描边、三幕渐变天空球与环境粒子、紫晶温室体积光柱、首领二阶段场景氛围突变。

## 基本操作

| 按键 | 功能 |
|---|---|
| `WASD` / 鼠标 | 移动 / 视角 |
| `左键` / `右键` | 武器双招式（闪避后按左键触发**冲刺斩**） |
| `Shift` | 独立多段闪避 |
| `C` | 反制蓝光蓄力攻击 |
| `E` / `X` / `Q` | 角色异能 / 战术异能 / 终极异能 |
| `V` 或 `鼠标中键` | 切换目标软锁定 |
| `T` | 转向当前目标 / 出口 |
| `F` | 选择并进入奖励门 / 交互 |
| `M` / `Tab` | 打开天赋图谱与共鸣路线追踪 |
| `H` | 使用急救 |
| `ESC` | 暂停并释放鼠标 |
