# 畸变前线 IV · 晴湾远征

独立 v4，保留 V1 / V2 / V3 和各自存档。单人对 AI 的第三人称动作搜打撤原型。

## 运行

推荐双击工作区根目录的 `畸变前线-第四版.html`，或 `启动第四版.cmd`。文件内包含脚本、Three.js、角色立绘、技能图标与菜单场景图，不需要联网或安装依赖。Chrome / Edge 需要开启硬件加速；点击进入猎场后使用标准 Pointer Lock，ESC 释放鼠标并暂停。

源代码版：在本目录运行 `node build.mjs`，随后运行 `node server.mjs`，访问 `http://127.0.0.1:4176/`。修改后重新生成独立文件：`node build-offline.mjs`。制作工作台重新启动后，当前版本会显示 v4，可从其版本页启动。

## 本轮变化

- 可移动范围由约 116 × 116 扩为 308 × 308，约为原来的 7 倍面积。六区分别为晴昼旧城、紫藤花园、封锁研究所、断轨枢纽、晴湾货场和远帆港区。
- 38 个物资箱，包含医疗、能源、普通、稀有箱；20 个初始 AI、核心精英、空投守卫与后续增援。库房可进入，屋顶、坡道、集装箱与钩索锚点支持垂直路线。
- 五种撤离条件：西岸排水闸始终开放；晴湾接驳艇消耗燃料；北线列车定时抵达；研究所救援坪需要通讯终端；南岸应急通道最后阶段开放。撤离会吸引敌人，离开、受击或窗口关闭会中断。
- 搜箱需要按住 F 并保持静止，移动、松开、攻击、受伤可中断。物资有稀有度、价值与重量；背包上限 28 kg，超过 20 kg 会减速，装不下的物资保留在箱内。
- 成功撤离将物资价值与已完成委托奖励存入独立仓库记录；死亡丢失本局物资与基因。仓库当前是累计资产记录，还没有商店或装备制造。
- 攻击改为前摇 / 命中 / 收势阶段，闪避和反制可以取消尚未命中的攻击。不同武器有不同节奏；重击、第三段、破势、受击后仰、刀弧、音效、短暂停顿与镜头冲击组合表现命中。
- 新增 ALT 奔跑、CTRL 潜行、移动加减速、闪避压身残影、落地与跳跃姿态。蓝色敌方攻击可用 C 反制。
- 每位角色新增 X 战术技能：灰烬封线、冰棱陷阱、留影诱饵、骨垒、脉冲嗅猎。骨垒当前实现为范围减伤与敌人迟滞，诱饵为局部干扰，没有实体导航障碍或独立诱饵 AI。
- 开局两份急救，H 注射 2.4 秒，受击、闪避或主动战斗操作中断。第 85 秒有固定位置补给事件，最后 150 秒边缘污染开始收拢。

## 操作

| 按键 | 功能 |
|---|---|
| WASD / 鼠标 | 移动 / 视角 |
| 左键 / 按住右键后松开 | 普攻 / 蓄力 |
| 1 / 2 | 双武器切换 |
| SHIFT / SPACE / G | 闪避 / 跳跃 / 朝向绿色锚点钩索 |
| ALT / CTRL | 奔跑 / 潜行 |
| C | 反制蓝色蓄力攻击 |
| E / X / Q | 主动异能 / 战术异能 / 终极异能 |
| 按住 F | 搜箱 / 激活通讯终端 |
| F | 收集基因 / 启动撤离 / 拾取余物 |
| H / R | 急救 / 消耗 5 基因进化 |
| M 或 TAB / T | 战术地图及背包 / 切换撤离导航 |
| 地图内 Z | 丢弃最后一件物资，可重新捡回 |
| ESC | 暂停并释放鼠标 |

战术地图不暂停世界。地图虚线路线表示目标方向，不是避障后的自动寻路。局部扫描仅显示近处敌人，裂爪嗅猎可临时扩大探测距离。

## 美术接入与 Blender

`dist/assets` 使用现有五角色独立立绘、十五个技能图标和晴湾港区概念图。立绘用于选人，技能图标用于 HUD，港区概念图用于出击简报。三维角色依照服装配色、肩甲、晶化手臂等特征补充几何造型；场景依据奶油建筑、青绿构件、珊瑚仓顶、紫色植被与海港起重机建立。

烬刃使用用户提供的 Tripo 高模制作的 Blender 游戏版。源文件位于 `../game-workbench/library/models/ember-tripo/Ember_Tripo.blend`，同目录包含带权重的 GLB。游戏版使用约 3.2 万个三角面、19 根身体骨骼和 2K 基础色贴图。长刀随当前武器挂到手部，游戏状态驱动跑步、挥刀、闪避和换装。GLB 内保留 PBR 贴图，游戏渲染使用卡通明暗分段。

场景按项目原画《晴昼旧城区》和《断轨之城全景》使用暖白建筑、青绿结构、珊瑚色轨道和淡紫树冠。战斗反馈沿用《刀光蓄力反制》的颜色与形状：暖白橙边弧光、蓝色折线和红白反制星芒。近战对手的血量与架势显示在上方；完美反制或判定成功的极限闪避会短暂开放左键追击窗口。

物资箱源文件为 `../game-workbench/library/models/field-cache/Field_Cache.blend`。箱盖围绕后铰链打开。街区加入了条纹店篷、过街线、换乘站钟面、天桥桁架和港机支撑，远处敌人使用共享的单网格模型。

## 验证与边界

运行 `node --test tests/*.test.mjs`。测试使用真实 Three.js 场景、碰撞数据、射线和游戏函数；WebGLRenderer 与 DOM 由测试替身提供，因而不验证像素画面或真实帧率。

已覆盖所有撤离条件及窗口边界、攻击命中帧和闪避取消、搜箱中断与满包余物、治疗、燃料只在成功时扣除、死亡不结算、角色与武器、地图通路、鼠标相对输入与锁定生命周期。采用实际碰撞体的网格洪泛验证所有撤离点、终端与地面箱子可达。

在本机 Chrome 离线打开独立 HTML，已验证出击、鼠标锁定、移动、攻击、切换武器和打开战术地图。AI 使用轻量避障，仓库为本地存档。
