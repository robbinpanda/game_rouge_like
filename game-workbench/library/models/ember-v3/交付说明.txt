烬刃 / EMBER — V3 动画、漫画风头部造型稿
2026-11-17

风格依据
用户明确否定 V2 的写实脸，要求动画感、漫画感。
V3 不再加载真人头部基础网格；使用本工作区新建的简化头部轮廓与五官几何。
保留此前的服装比例、装备和基础骨架，本轮主要校正头部与整体材质风格。

本轮修改
1. 用连续的简化轮廓重新搭头部，收整下颌、缩短下半脸和头颈衔接。
2. 放大眼形和虹膜，做上挑外眼角、深色上眼线与粗眉，加入少量明确的眼睛高光。
3. 鼻子改为简化鼻梁与小鼻尖；嘴改成细线，移除真人鼻翼、唇肉、皮肤散射。
4. 重新制作有方向的尖端发束，使用发束明暗面区分体积，修复头皮穿出问题。
5. Blender 材质采用分区色阶；面部只有简洁的主色和暗面，无写实皮肤反光。
6. GLB 将这些色阶烘焙为顶点色并使用 unlit 材质，使常规 glTF 预览仍显示漫画配色。

主要文件
EMBER_v3.blend：可编辑模型、原画参考、基础骨架、三个测试动作、可调色阶节点及摄影棚。
EMBER_v3.glb：约 4.80 MB，43 根骨骼、11 个蒙皮网格、自包含文件。
01_hero.png：全身实际模型渲染。
02_face.png：三分之四侧面近景。
03_face_front.png / 04_face_profile.png：正面与侧脸检查。
05_back.png / 06_joint_test.png：背面与基础关节测试。
07_head_turnaround.png：同一模型的正面、三分之四侧面和侧面。
08_actual_glb.png：重新导入交付 GLB 后的真实材质渲染，没有替换导出材质。
model_audit.json / export_verification.json：结构及独立 GLB 回读检查。

检查
68,434 三角面，38,158 个源顶点，43 骨骼，11 个蒙皮网格。
结构检查：未发现未绑定顶点或超过四根骨骼影响的顶点。
GLB 独立回读：待机、原地行走和关节范围测试动作各采样五个时间点。
导出色阶检查：所有图元包含 COLOR_0，材质含 KHR_materials_unlit。

打开方法
在 Blender 打开 EMBER_v3.blend；或双击工作区根目录“打开烬刃漫画风模型.cmd”。
工作台资产库搜索“烬刃 V3”，可旋转查看 GLB。
制作脚本位于 game-workbench/library/models/ember-v3，运行 build_ember.py 可重建。

当前边界
这是待审阅的漫画风造型稿，不代表用户已确认角色定稿。
Blender 的明暗根据表面方向计算；GLB 的明暗色块已烘焙，会随蒙皮移动，不随场景灯光改变。
如要正式接入游戏动态光照，应在引擎中实现对应的卡通色阶材质。
尚无面部表情绑定、手绘纹理图集、最终生产拓扑、LOD 和正式技能动画。
衣服褶皱、手部握持和极限动作穿插仍需要细化；未更改第四版游戏运行时代码。
V1 / V2 文件保留，V2 的写实面部方向不作为当前风格依据。
