烬刃 / EMBER — R4 立绘结构与棱角风格迭代
2026-11-17

本轮明确风格要求
保留原立绘的动画、漫画感，以及身体和衣服棱角分明的大折面。
改善“脸太平、神态呆、头发僵硬”，不等于把全身处理成圆润写实的曲面。
参考：output/aberrant-character-kit-v3/烬刃/03_独立立绘.png 与 01_三视图.png。

修改内容
1. 重新塑造眼窝、眉骨、颧骨、鼻梁、嘴部和下颌的前后关系；眼睛有弧度，配有眼睑厚度。
2. 收紧眉眼间距，使用稍不对称的眉形和深色圆形虹膜，嘴形保持克制。
3. 发束缩短并交叠，根部融合为连续体积，保留尖端与大块面轮廓，去除悬空硬弧线和杂乱小凸起。
4. 重做开襟短外套、高领与折叠翻领；肩臂与卷袖保留硬边折线，增加胸前结构折面。
5. 调整裤装、腰带倾斜、偏侧衣摆及肩甲比例；裤腿和前臂使用清楚的大块面。
6. 非持剑手增加轻微自然弯曲；原有三个基础测试动作保留。

交付文件
EMBER_v4.blend：可编辑模型、材质、参考图、基础骨架、三个测试动作和摄影棚。
EMBER_v4.glb：自包含骨骼模型，约 5.86 MB。
01_hero.png：全身模型渲染。
02_face.png / 03_face_front.png / 04_face_profile.png：面部近景、正面与侧面。
05_back.png / 06_joint_test.png：背面和关节测试。
07_head_turnaround.png：同一实际模型的三个头部角度。
08_actual_glb.png：原样回读最终 GLB 后的材质渲染。
09_original_art_and_model.png：左为原立绘，右为实际 R4 模型；原立绘不是模型渲染。
model_audit.json / export_verification.json：模型结构与独立导出回读检查。

检查与打开
43 根骨骼，11 个分组蒙皮网格。具体顶点与三角面数见 model_audit.json。
导出回读检查资源自包含、颜色通道、骨架和待机/原地行走/关节测试三个片段。
每个测试片段采样五个时间点；交付包中的报告与最终 GLB 哈希一致。
在 Blender 打开 EMBER_v4.blend，或双击工作区根目录“打开烬刃棱角风模型.cmd”。
工作台搜索“烬刃 R4”可查看当前模型资产。
制作脚本保存在本工作区的 game-workbench/library/models/ember-v4 中。

当前边界
本轮是待审阅的造型迭代，仍不能等同于原画完全还原或最终角色定稿。
Blender 材质使用分区明暗和局部环境遮蔽；GLB 使用烘焙顶点色与 unlit 材质，维持漫画配色。
GLB 的明暗随蒙皮移动，不响应场景动态光源；正式游戏中需配置对应的卡通材质。
仍无表情控制器、最终生产拓扑、贴图图集、LOD 或正式技能动画；极端动作穿插与握剑仍需细化。
没有更改第四版游戏运行时代码。旧模型文件均保留。
